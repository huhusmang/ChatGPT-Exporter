# ChatGPT Exporter v2.0

将 ChatGPT 对话导出到本地的 Chrome 扩展。v2.0 面向大量对话的持续导出：每条对话分别保存为 JSON 和 Markdown，并支持跳过已完成内容、限流冷却和按日期选择。

## 功能

- 个人空间、团队空间和项目空间的对话导出。
- 每条对话生成一对文件：`对话标题_对话ID.json` 与 `对话标题_对话ID.md`。
- 文件默认保存到 `下载\ChatGPT Exports\<空间标识>\`。
- 已成功导出的对话会被记录；再次导出时自动跳过。即使扩展记录丢失，也会检查下载目录中完整的 JSON/MD 文件对。
- 支持按标题、项目、归档状态、创建时间或更新时间筛选对话。
- 选择对话窗口采用渐进加载：第一批列表到达后即可筛选和导出，其余内容继续在后台加载。
- ChatGPT 数据请求统一排队，正常请求间隔为 10–15 秒。
- 遇到 HTTP 429 限流时不刷新 ChatGPT 页面：等待 1 分钟后重试当前请求；若继续限流，等待会逐步增加到 2、4、8 分钟，最长 15 分钟。
- 自动处理 Windows 不支持的文件名、不可见字符和过长标题。
- 可选导出附件；附件模式使用兼容 ZIP 导出，不支持逐条续传。

## 安装

1. 在 Chrome 打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目中的 `chrome-extension_1.6` 文件夹。
5. 打开或刷新一次 ChatGPT 页面。

以后更新代码时，在 `chrome://extensions/` 点击此扩展的“重新加载”，再刷新 ChatGPT 页面一次。

## 使用方法

1. 登录 ChatGPT 并打开任意 ChatGPT 页面。
2. 点击扩展图标，选择“打开导出面板”。
3. 选择个人、项目或团队空间。
4. 选择“导出全部”或“选择对话导出”。

### 导出全部

扩展先列出需要处理的对话，再按顺序下载每条对话。已完成的对话会自动跳过，因此中断后重新执行同一空间的导出即可继续。

### 选择对话导出与日期筛选

选择“选择对话导出”后，第一批对话通常会先出现；此时即可：

- 搜索标题、项目名称或对话 ID；
- 按项目/项目外、活跃/归档状态筛选；
- 按创建时间或更新时间设置日期范围；
- 勾选需要的对话并开始导出。

列表未完全加载时，窗口会显示后台加载状态；之后加载到的对话会自动加入当前筛选结果。

## 限流与续传

ChatGPT 可能会限制短时间内频繁读取对话记录。扩展不会通过刷新页面来绕过该限制。

- 正常情况下：每次数据请求之间会等待 10–15 秒。
- 收到 429 后：当前请求保留在队列中，先等待 1 分钟再自动重试。
- 如果仍被限流：冷却时间会逐步增加，最长 15 分钟。
- 已下载成功的对话不会重新下载。

导出期间请保持 ChatGPT 标签页打开，避免同时使用多个相同扩展版本或手动连续发起多次导出。

## 文件与进度记录

每条对话只有在 JSON 和 Markdown 都下载完成后才会记为完成。若下载失败，该对话不会被误跳过；重新导出时会再次处理它。

如果确实需要重新下载某些已完成的对话，可在“选择对话导出”窗口中使用“清除已导出记录”。

## 常见问题

### 一直显示“正在加载列表”怎么办？

v2.0 会在第一批列表到达后开放筛选和选择。若状态显示正在限流，请保持页面打开，等待提示的时间结束后会自动继续，无需刷新页面。

### 出现 `Invalid filename` 怎么办？

v2.0 会自动清理非法字符并截断过长标题。请确认扩展已重新加载且 ChatGPT 页面已刷新，然后重新执行导出；失败的对话不会被标记为已完成。

### 为什么会有同名文件或 `(1)`、`(2)`？

这表示浏览器曾下载过同一名称的文件。文件名末尾的对话 ID 才是识别同一对话的依据。当前版本会在开始导出前检查完整的 JSON/MD 文件对，并跳过已经完成的对话。
